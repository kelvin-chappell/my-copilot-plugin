# my-copilot-plugin

## Playwright Test Agents

The `guardian-e2e-verifier` orchestrator agent delegates end-to-end testing work
to three Playwright Test Agents: `@playwright-test-planner`,
`@playwright-test-generator`, and `@playwright-test-healer`. These are
generated by Playwright itself via:

```
npx playwright init-agents --loop=copilot
```

Because these agent definitions are version-locked to the installed
Playwright release and Playwright recommends regenerating them whenever
Playwright is updated, they are **not** hand-maintained in this repo. Instead,
the `.github/workflows/sync-playwright-agents.yml` workflow runs on a weekly
schedule, installs the latest `@playwright/test`, regenerates the agent files,
collects them into `agents/` (via `scripts/collect-agents.mjs`), and commits
the changes if anything differs. This keeps the bundled agents tracking the
latest Playwright release without drifting.

To refresh the agents on demand (e.g. right after a new Playwright release),
trigger the workflow manually from the Actions tab using its
`workflow_dispatch` trigger, or via `gh workflow run sync-playwright-agents.yml`.
